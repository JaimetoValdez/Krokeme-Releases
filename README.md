# Krokeme

Krokeme es una biblioteca visual local para guardar y organizar fotos, videos, documentos, notas y enlaces en Windows.

- [Descargas y notas de versión](https://github.com/JaimetoValdez/Krokeme-Downloads/releases)
- [Reportar un error](https://github.com/JaimetoValdez/Krokeme-Downloads/issues/new)
- [Proponer una mejora o hacer una pregunta](https://github.com/JaimetoValdez/Krokeme-Downloads/discussions)

La primera beta está en preparación. Al reportar un error, indica la versión de Krokeme y de Windows, los pasos para reproducirlo y qué esperabas que ocurriera. Usa ejemplos sin datos personales.
